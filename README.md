# 📱 Telegram Broadcaster с Railway

Бот для управления рассылкой сообщений в Telegram от вашего аккаунта, развернутый на Railway.

## ⚙️ Подготовка

### 1️⃣ Получите API ID и API Hash

1. Перейдите на https://my.telegram.org/apps
2. Войдите в свой аккаунт Telegram
3. Создайте приложение и получите:
   - `API_ID`
   - `API_HASH`

### 2️⃣ Узнайте свой ID

1. Найдите бота @userinfobot в Telegram
2. Напишите ему что-нибудь
3. Скопируйте значение `Id` - это ваш `ADMIN_ID`

## 🚀 Деплой на Railway

### Способ 1: Через GitHub (Рекомендуется)

1. **Создайте репозиторий на GitHub**
   - Название: `rassil` (или любое другое)
   - Сделайте его **Private**

2. **Залейте код**
   ```bash
   git clone https://github.com/YOUR_USERNAME/rassil.git
   cd rassil
   # Скопируйте все файлы сюда
   git add .
   git commit -m "Initial commit"
   git push
   ```

3. **Перейдите на Railway**
   - https://railway.app
   - Нажмите "Login with GitHub"
   - Авторизуйтесь

4. **Создайте новый проект**
   - Нажмите "New Project" → "Deploy from GitHub repo"
   - Выберите репозиторий `rassil`
   - Railway автоматически обнаружит `Dockerfile`

5. **Установите переменные окружения**
   - В Railway перейдите в "Settings" или "Variables"
   - Добавьте:
     ```
     API_ID=123456789
     API_HASH=your_api_hash_here
     ADMIN_ID=987654321
     ```

6. **Деплой автоматически запустится**
   - Railway будет строить Docker образ
   - Бот будет запущен

---

### Способ 2: Через Railway CLI

```bash
# 1. Установите Railway CLI
npm i -g @railway/cli

# 2. Войдите в Railway
railway login

# 3. Создайте проект
railway init

# 4. Установите переменные
railway variables set API_ID=123456789
railway variables set API_HASH=your_api_hash_here
railway variables set ADMIN_ID=987654321

# 5. Деплой
railway up
```

## 🔑 Переменные Environment (Railway Variables)

| Переменная | Значение | Пример |
|---|---|---|
| `API_ID` | Ваш API ID | `123456789` |
| `API_HASH` | Ваш API Hash | `abcdef123456` |
| `ADMIN_ID` | Ваш ID в Telegram | `987654321` |

## 📖 Использование бота

1. **Напишите боту** `/start` в Telegram

2. **Команды:**
   - `📤 Рассылка` - Отправить сообщение в выбранные чаты
   - `💾 Добавить чат` - Добавить новый чат
   - `📋 Список чатов` - Просмотр сохраненных чатов
   - `🗑 Удалить чат` - Удалить чат из списка

3. **Добавление чата:**
   - Отправьте ID чата, ИЛИ
   - Переслите сообщение из нужного чата

## ⚠️ Важно

### Первый запуск
- При первом запуске Railway попросит авторизацию
- Вам нужно отправить номер и код подтверждения боту в Telegram
- Сессия сохранится автоматически

### Логи
- Смотрите логи в Railway Dashboard → Logs
- Если есть проблемы с авторизацией, они будут видны там

### Перезагрузка
- Если сессия потеряется, Railway перезагрузится и попросит авторизацию снова
- Данные о чатах сохраняются в `chats.json`

## 🐛 Решение проблем

### "Phone number is invalid"
- Используйте формат с кодом страны: `+79999999999`

### "Phone code invalid"  
- Код действует 5 минут
- Проверьте время на сервере Railway

### "Waiting for 2FA"
- Введите пароль двухфактора

### Бот не отвечает
- Проверьте логи в Railway Dashboard
- Убедитесь, что `ADMIN_ID` правильный
